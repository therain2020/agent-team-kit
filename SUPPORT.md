# Support

## Where to ask

- **Questions and ideas:** GitHub Discussions (Q&A and Ideas). Include your
  `kit doctor --json` output and the command you ran.
- **Bugs:** open a "Bug report" issue. The template asks for a reproduction and
  the doctor output.
- **Feature requests:** open a "Feature request" issue and describe the user
  moment that is broken.
- **Team packs:** use the "Team pack submission" issue template.
- **Security:** follow [SECURITY.md](./SECURITY.md). Never post secrets.

## Before asking

1. Run `bun run kit doctor` and read the suggested fix for each warning.
2. Check [docs/install.md](./docs/install.md) and [README.md](./README.md).
3. Search existing issues and discussions.

## What to include

- OS, Bun, Node and Docker versions;
- the exact command and its full output (redact keys and private data);
- run id, artifact id or digest when the problem is in a run;
- whether the console or the CLI is affected.

## Expectations

This is a community project. Responses are best-effort, usually within a few
business days; there is no SLA. Maintainers may close issues that cannot be
reproduced or that fall outside the documented boundaries.
